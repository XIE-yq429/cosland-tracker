COSLAND 旺季产品与竞品 · 排名&价格监测 —— 监测站点
==========================================================

【怎么打开】
双击本目录下的 index.html 即可（推荐 Chrome / Edge）。
整个文件夹可复制到 U 盘、其他电脑或任意无网环境，无需联网、无需安装软件。

【目录内容】
  index.html        首页：KPI 概览 + 最新一日快照 + 站点导航
  dashboard.html    交互式看板：日期切换 / 筛选 / 搜索 / 点行看趋势 / 自定义查询（单文件自包含）
  advice.html       运营建议总览：规则引擎按滚动 7 个数据日生成，可切换日期
  daily/            每日汇总报告（9 份）+ 索引页
  trend/            周趋势图 PNG（38 张，每周五出图）+ 画廊索引页
  data/             原始 JSON / 监测清单 / 全量 CSV

【口径说明】
  1. 价格为 BuyBox 主价；R21 加拿大站为 CAD，其余为 USD。
  2. BSR 优先取子类排名，缺失时回退大类；长期无 BSR 说明 Listing 未被收录。
  3. 对比列＝相对上一抓取日的产品侧变化；价格>10% 或 BSR>20% 计入显著变动。
  4. 建议由规则引擎自动生成（价格变动≥5% / 排名变动≥15% / 竞对同期动作 / 期末价差位势），
     仅作决策参考，请结合库存、毛利、广告投放与季节性综合判断。
  5. 竞对价格取页面默认变体价，可能因变体切换或优惠券变动，不等于真实成交价。

【怎么更新】
  主控电脑（运行自动化任务的机器）每天跑完抓取后执行：
      python build_offline_site.py
  会重新生成本目录（含最新数据与建议）。把新的 offline_site 文件夹整体覆盖过来即可。

  如需"每天自动更新 + 在线新增监测"，请在主控电脑访问 http://localhost:8765
  （自动化目录双击 start_dashboard.bat 启动本地服务）。
